# Patil Law Firm and Legal Advisors

GitHub Pages website for **Adv. Vivek D. Patil, B.A. LL.B.**

## Working enquiry system

The website has two enquiry methods:

1. **WhatsApp Inquiry** — the visitor fills in the form and the website creates a WhatsApp message to **+91 90286 56379**. This works on a static GitHub Pages website without a server.
2. **Email Inquiry** — opens the visitor's email application with the enquiry already prepared for **advvivek07@gmail.com**.

This is intentionally designed so enquiries do not depend on a paid backend.

## Publish on GitHub Pages

Upload these files to the repository root:
- `index.html`
- `logo.jpg`

Then:
**Repository → Settings → Pages → Deploy from a branch → main → / (root) → Save**

## Important

GitHub Pages is a static hosting service. It cannot itself receive/send form submissions to your email without a third-party backend. The current site therefore uses WhatsApp and the visitor's email application as the reliable enquiry channels.

For the strongest lead-capture setup later, a dedicated form backend can be connected to the same form.
